# Changelog

## 1.0 and 2.0 preview

The first release line. Everything below is in the app today.

- A parallel scan of your home folder with hard links counted once and no symlink following.
- Overview, Explore (a treemap with semantic textures) and Recommended pages with an inspector.
- A staging queue, a cleanup sheet that you confirm, Trash by default, and script export.
- The active-work guard for repositories with uncommitted or unpushed work.
- A command palette (<kbd>⌘K</kbd>), Vim-style treemap keys and background rescans.
- A guided first run for Full Disk Access.
- Pro: palette batch commands and saved filters, with 7-day trials and offline license keys.

Other Pro features are planned for 2.x. They are listed as coming on the [features page](/features).
